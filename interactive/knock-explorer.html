Saab Trionic 5 — knock detection, end to end

MCS Green Giant V3 — identical to factory 4780656 except Apc_knock_back (5→0) and Fuel_knock_mat. Values below are real calibration data from your binary.

1 · Signal chain — the spark plug IS the knock sensor

Cylinder / plug gapAfter combustion, ionized gas conducts an ion current (80 V bias, sensed at coil low-voltage side). Knock = chamber pressure oscillation modulating that current.
→
DI cassetteBand-pass ≈ 7 kHz → sine burst, amplitude = knock severity. One shared output. No piezo KS exists on T5; ion also gives misfire + crank sync (no cam sensor).
→
ECU pin 44Shared by all 4 cylinders — attribution by timing: ECU knows who just fired.
→
TPU hardware windowPWM strobe opens counter 30–45° to 60–75° after each spark (ion/combustion phase). No software per pulse.
→
Window pulse countCount ≈ amplitude × time. Scale 0…~90. Baseline count ≠ 0 — spark-discharge energy leaks into the window; a healthy engine counts 20–45.

Severe sustained knock → boost control falls back to basic charge pressure (ISAT shows cause “KNOCK CONTROL”: bad fuel or dying cassette). Per-cylinder offsets exit as Ret_mangd retard demand → spark + dwell. MCS also enriches differently while knocking (Fuel_knock_mat, peak 1.51× vs stock 1.61×).

4 · Ion-path watchdog (the Knock_diag_level story)

cassette line alive (window count > 50)
battery ≥ DI_cassette_U_limit (no sag)
rpm proxy ≥ 800, ignition on
no-signal timer (fault at 10 s)
healthy timing… measurement inhibited (batt/rpm) LATCHED 0x28/0x2C + Knock_frame
1500 clean cycles → auto-clear
Every pass of F_0005C34A:
diag_level > 50 → timer ← now (“proof of life” — spark ringing keeps a healthy line well above 0; wire-off reads ≈0 forever).
≤ 50 and battery healthy and rpm ≥ 800 → timer not refreshed; after 10 s → latch fault: set knock-fault bit, error code 0x28/0x2C, snapshot 25 longs of Error_frame → Knock_frame.
Battery sag? cassette output legitimately shrinks with supply voltage → watchdog declines to convict (that's the DI_cassette_U_limit gate).
While latched, watchdog skips itself; recovery only via 1500 clean ignition cycles.

T5 knock uses no smooth temperature table — just these gates (+ the 40–60 kPa Knock_press_limit map and the battery DI_cassette_U_limit gate). Below 40 °C the ECU never retards or derates for knock. Sensor failed? Detection is force-enabled so a dead sensor can't disarm protection.
