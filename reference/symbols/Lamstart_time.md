
# Lamstart_time

State word (RAM) · (RAM)

**Value in factory 4780656:**

Ticks since first closed-loop entry this key-on (0 = never).

**Function:** The lambda-startup gate runs its cold-timer logic only while this is 0.

**Code path:** Tested 0x5DF0C.
