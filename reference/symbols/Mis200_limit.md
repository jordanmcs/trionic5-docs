
# Mis200_limit

**Value in factory 4780656:** runtime — units: misfires / 200 rev (min 1)

**Function:** Interpolated pass/fail limit for the 200-rev window, from Mis200_map (576-byte rpm/boost grid).

**Code path:** Interpolation 0x6185C–0x6189C
