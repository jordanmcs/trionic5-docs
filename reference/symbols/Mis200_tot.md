
# Mis200_tot

State word (RAM) · 0x10D8

**Value in factory 4780656:** runtime — units: misfires / 200 rev

**Function:** Sum of the 200-revolution window; compared against the diagnostic threshold (constant 0x0190) to pick the worst cylinder and set the general misfire DTC. Live-data id 0x56.

**Code path:** Diagnostic evaluation 0x5C4xx–0x5CB6x
