# Tid_konst

Calibration word (flash)  ·  0x40BA2 -> 0x4BF2

**Value in factory 4780656:** 0x02EE — units: 4 us ticks (750 = 3.0 ms)

**Function:** fixed idle injection time override

**Code path:** 0x6E598 when Pgm_mod[1].3 and idle
