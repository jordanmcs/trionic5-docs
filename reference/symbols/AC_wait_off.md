# AC_wait_off

Calibration table, 8 bytes  ·  ROM 0x41112 -> RAM 0x600E

**Value in factory 4780656:** bytes: 0x12 0x11 0x0E 0x0E 0x0C 0x06 0x04 0x04

**Function:** Per-rpm-row delay (ticks) from AC release to restore. Factory 0x12 down to 0x04.

**Code path:** 0x6D2xx AC path
