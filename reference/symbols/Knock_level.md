
# Knock_level

State word (RAM 0x112C) · RAM 0x112C

**Value in factory 4780656:** 0…~90 pulse counts

**Function:** Current per-window pulse count. The quantity every threshold in this subsystem is judged against or derived from.

**Code path:** F_00047CE0 writes; evaluation and K-adapt read.
