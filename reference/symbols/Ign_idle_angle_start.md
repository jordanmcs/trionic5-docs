# Ign_idle_angle_start

**Value in factory 4780656:** 180 (=18.0 deg) — units: 0.1 crank degree

**Function:** idle angle substitute when idle out-of-band exceeds Diag_tid (anti-stall recovery)

**Code path:** F_0006F450 0x6F76A
