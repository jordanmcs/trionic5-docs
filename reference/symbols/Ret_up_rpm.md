# Ret_up_rpm

Calibration word (flash) · ROM 0x41762

**Value in factory 4780656:** 150 (=1500 rpm) — units: rpm x10

**Function:** upper rpm bound for all-cyl-knock fuel enrichment window

**Code path:** F_000694B2 0x694C2
