# Insp_vinkel

State word (RAM) · RAM alias; scheduled copy 0x1072

**Value in factory 4780656:** runtime — units: crank degrees

**Function:** injection angle for next TPU event (+0/180/360/540 per cylinder, firing 1-3-4-2)

**Code path:** written 0x69962, read 0x6CB98/0x6CC4E
