State byte (RAM) · 0x1D22

**Value in factory 4780656:** runtime — units: flag/frame

**Function:** Misfire-logic mode flag (plus frame bytes) handling misfire behaviour during the fuel-heating mode, where combustion is legitimately abnormal.
