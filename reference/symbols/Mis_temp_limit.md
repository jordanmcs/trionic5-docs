# Mis_temp_limit

Calibration byte  ·  ROM 0x4289C -> RAM 0x5AF6

**Value in factory 4780656:** bytes: 0xD8

**Function:** No misfire counting below this coolant temperature (book).

**Code path:** Gate 0x64B2C region
