
# Misf_ignc4_idle

State long (RAM; RE-workspace label — no symbol-table entry)

**Value in factory 4780656:** runtime — units: combustion counts

**Function:** Idle snapshot of Ign_counter_mis for cylinder 4: taken while idling, and the later difference against the live counter gates misfire evaluation in the idle band.

**Code path:** Snapshot 0x64AF4; clears 0x64D4C/0x64DE4; difference gate 0x65C3E
