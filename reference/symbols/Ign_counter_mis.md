
# Ign_counter_mis

State long (RAM; RE-workspace label — no symbol-table entry)

**Value in factory 4780656:** runtime — units: combustion counts

**Function:** Running combustion counter — the time base for every misfire window, inhibit and snapshot below. Incremented once per detected combustion event.

**Code path:** Increment 0x63A80; snapshot block 0x38DE–0x3920; copy example 0x640D0
