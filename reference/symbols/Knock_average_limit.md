
# Knock_average_limit

Runtime word (RAM)  ·  derived from Knock_average_tab

**Value in factory 4780656:** 20–80 by rpm

**Function:** Live comparison threshold for the four-cylinder average offset; exceeding it sets the documented Knock_status "average > limit" bit.

**Code path:** Computed 0x61AD4; compared in offset engine (0x62A36 etc.).
