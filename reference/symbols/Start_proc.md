# Start_proc

**Value in factory 4780656:**

Raw **128** (1 B) at ROM `0x040F10`.

**Function:** Scaling divisor (128) applied when the cranking pulse is written into the injection-time array.

**Code path:** 0x6EFFA/0x6F090.
