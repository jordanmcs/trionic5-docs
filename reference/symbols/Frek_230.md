# Frek_230

Calibration word (flash, 16-bit) · ROM 0x41670, RAM 0x5EA6

**Value in factory 4780656:** 90 — units: Hz

**Function:** valve PWM frequency below 2300 rpm

**Code path:** 0x72530/0x7258A -> 0x3A88
