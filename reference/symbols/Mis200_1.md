
# Mis200_1

State word (RAM) · 0x10D0

**Value in factory 4780656:** runtime — units: misfires / 200 rev

**Function:** Per-cylinder misfire count for cylinder 1 in the 200-revolution OBD window. Mirrored into the live-data image (id 0x58+); the worst cylinder is selected across Mis200_1..4 for the per-cylinder DTC (P0301–P0304).

**Code path:** Worst-cylinder compare 0x5C590–0x5C5B6; live-data mirror 0x5F2E6+
