# Frek_250

Calibration word (flash, 16-bit)  ·  ROM 0x41672, RAM 0x5EA8

**Value in factory 4780656:** 70 — units: Hz

**Function:** valve PWM frequency above 2500 rpm

**Code path:** 0x72546/0x7259C -> 0x3A88
