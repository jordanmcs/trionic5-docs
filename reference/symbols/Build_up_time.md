# Build_up_time

**Value in factory 4780656:**

Raw **30** (1 B) at ROM `0x040534`.

**Function:** Build-up window (ticks) for the before-start priming stage in normal conditions.

**Code path:** 0x6EF32 (select when [Kyl_temp](Kyl_temp.md) ≥ switch point).
