
# Start_max

Calibration scalar  ·  ROM 0x040712

**Value in factory 4780656:**

Raw **14** (2 B) at ROM `0x040712`.

**Function:** Post-catch injection count at which blended cranking fuel is fully replaced by running fuel.

**Code path:** 0x6F158/0x6F164.
