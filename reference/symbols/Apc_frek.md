


# Apc_frek

Calibration byte (flash)  ·  ROM 0x4153E



**Value in factory 4780656:** 0



**Function:** Optional knock-signal frequency threshold for a boost-module monitoring branch. At zero the unsigned comparison can never fire — dead code in both binaries.



**Code path:** CMP.B/BCS at 0x723F2.
