# Start_time

**Value in factory 4780656:**

Cranking duration counter for the current start (ticks while rpm below [Start_time_rpm_lim](Start_time_rpm_lim.md)).

**Function:** Mirrored into the diagnostic frame array (0x1D18).

**Code path:** 0x6D00C–0x6D022.
