
# Knock_reduce

Calibration word (flash)  ·  ROM 0x417DA

**Value in factory 4780656:** 15 = 1.5° (0.1° units)

**Function:** Retard increment added to a cylinder's ignition offset on each confirmed knock event.

**Code path:** Read by the offset engine, F_00062842 region.

Part of [T5 Knock Detection and Adaptation](../../guide/knock-detection-and-adaptation.md) · index: [T5 Symbols](../symbol-index.md)
