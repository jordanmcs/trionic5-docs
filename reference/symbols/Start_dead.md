# Start_dead

**Value in factory 4780656:**

Cranking dead-pulse counter from [Start_dead_tab](Start_dead_tab.md); zero in calibration (feature disabled).

**Function:** Gate for dead pulses during cranking.

**Code path:** 0x6F0DC/0x6F106.
