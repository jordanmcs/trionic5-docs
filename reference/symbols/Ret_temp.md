
# Ret_temp

State byte (RAM) · (RAM)

**Value in factory 4780656:**

Warm-up ignition retard multiplier, ×1/128 (1.40…2.00), interpolated from [Retard_temp](Retard_temp.md).

**Function:** Applied in the ignition-time computation during warm-up. Not knock-related despite adjacent research.

**Code path:** Written 0x6D428; read 0x6C2DC/0x6EC0C.
