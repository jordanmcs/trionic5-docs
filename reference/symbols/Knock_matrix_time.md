
# Knock_matrix_time

Calibration word (flash)  ·  ROM 0x428B8

**Value in factory 4780656:** 12000 (ms)

**Function:** Hold/refresh period for knock reference matrix bookkeeping (matrix re-interpolated and offset decay windows advance on this 12 s tick).

**Code path:** 32-bit ms tick at 0x3B02; elapsed tracked at 0x4658.
